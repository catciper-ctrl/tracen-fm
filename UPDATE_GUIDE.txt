TRACEN FM 업데이트 방법

1. 압축을 풀고 TRACEN-FM 폴더 안의 파일과 images 폴더를 복사하세요.
2. GitHub Desktop에서 Repository > Show in Explorer를 누르세요.
3. index.html이 있는 저장소 폴더에 붙여넣고 같은 파일은 덮어쓰세요.
   TRACEN-FM 폴더 자체나 압축파일을 넣지 마세요. .git 폴더는 지우지 마세요.
4. GitHub Desktop의 Summary에 업데이트 내용을 쓰고 Commit to main을 누르세요.
5. Push origin을 누르세요. GitHub Pages 배포가 끝나면 Ctrl+F5로 새로고침하세요.

이번 수정: 같은 턴에 현역 여러 명이 동일 조건의 신마전·미승리전에 각각 출전할 수 있습니다. 일반 레이스의 부문별 중복 출전 제한과 개인별 턴당 활동 제한은 유지됩니다.
