TRACEN FM · GitHub Desktop 업데이트 방법

이 ZIP은 GPTSITE 최신 버전입니다. ZIP 자체를 저장소에 올리지 마세요.

1. 게임에서 저장 내보내기로 현재 세이브를 보관하세요.
2. GitHub Desktop에서 기존 tracen-fm 저장소와 main 브랜치를 선택하세요.
3. Fetch origin을 누르고 Pull origin이 나타나면 먼저 눌러 기존 저장소를 동기화하세요.
4. Repository → Show in Explorer로 저장소 폴더를 여세요.
5. 저장소의 기존 images 폴더를 삭제하세요. 덮어쓰기만 하면 삭제 대상 원본 이미지가 남습니다.
6. 압축을 풀어 TRACEN-FM 폴더 안의 모든 파일과 images 폴더를 저장소 루트에 복사하고 덮어쓰세요.
   index.html과 images가 기존 index.html과 같은 위치에 있어야 합니다.
   TRACEN-FM 폴더 자체나 ZIP 파일을 올리는 것이 아닙니다.
7. .git 폴더, .github 폴더, CNAME이 있다면 그대로 유지하세요.
8. GitHub Desktop의 Changes에서 파일 변경 및 이전 이미지 삭제를 확인하세요.
9. Summary에 Update TRACEN FM을 입력하고 Commit to main을 누르세요.
10. Push origin을 누르세요.
11. GitHub 저장소의 Actions에서 Pages 배포가 완료되면 게임 사이트를 Ctrl+F5로 새로고침하세요.

현재 Pages가 main / (root)에서 배포 중이면 설정 변경은 필요 없습니다.
